# 校園學餐等待時間規劃系統 (Campus Cafeteria Waiting Time Planner)

本專案為資料結構課程的期末專案 Demo。透過互動式前端網頁，動態演示 **圖形最短路徑演算法 (Dijkstra's Algorithm)** 與 **氣泡排序法 (Bubble Sort)** 的真實應用場景。

---

## 🏫 專案背景與用途
在午餐或晚餐尖峰時間，肚子餓的學生往往面臨兩大抉擇難題：
1. 去哪一家學餐排隊最快？
2. 走過去加排隊製作的時間，會不會讓我下一堂課遲到？

本系統模擬一個校園學餐等待時間規劃器，整合了各教學大樓與餐廳之間的「步行時間權重」和餐廳現場的「排隊時間」，為學生即時規劃並計算總耗時。

---

## 🛠️ 技術規格
- **技術棧**：純 HTML5 / CSS3 (含 Glassmorphic 磨砂玻璃主題) / ES6+ JavaScript。
- **無框架限制**：不使用 React、Vue、NPM 或後端伺服器，直接於瀏覽器中雙擊 `index.html` 即可流暢執行。
- **資料檔案**：
  - `data/restaurantData.js`：儲存學餐餐廳列表與各項即時排隊時間。
  - `data/campusGraph.js`：以鄰接串列儲存校園各大樓至學餐餐廳的無向帶權圖路徑。

---

## 📈 核心資料結構與演算法

### 1. 校園地圖路徑 — 帶權圖與戴克斯特拉演算法 (Weighted Graph & Dijkstra's Algorithm)
- **資料結構**：採用 **鄰接串列 (Adjacency List)** 儲存校園各大樓節點與連接通道的權重（步行時間）。
- **運作邏輯**：當使用者選擇起點大樓與終點學餐時，系統自動載入 `campusGraph.js`，執行 Dijkstra 最短路徑尋訪。
- **視覺化追蹤**：Dijkstra 演算法執行後，系統會自動在畫面上渲染出完整的步行最佳路線大綱，並動態加總排隊等待時間。

### 2. 學餐排隊排序 — 陣列與氣泡排序 (Array & Bubble Sort)
- **資料結構**：採用 **物件陣列 (Array of Objects)** 儲存學餐餐廳清單。
- **運作邏輯**：當點擊「依時間排序」按鈕，系統會使用自訂的 Bubble Sort 對陣列進行原地排序 (In-place Sort)。
- **運作特點**：演算法在排序過程中逐項比較相鄰的等待時間並進行置換，完成後即時重新渲染左側的餐廳列表看板。

## 🚀 執行與展示方式
1. 將整個專案資料夾下載至本機。
2. 進入資料夾，**按兩下 `index.html` 即可在瀏覽器中開啟**。
3. **三分鐘展示示範流程**：
   - 點擊左側 **「依時間排序 (Bubble Sort)」**，觀察左側卡片依照等待時間由短到長重新排列。
   - 在右側規劃機中，將起點設為 **「第一教學大樓」**，終點設為 **「文華食堂」**，並設定後續行程時間為 **「13:00」**。
   - 點擊 **「執行 Dijkstra 路徑規劃」** 按鈕。
   - 查看動態顯示的總耗時明細、預計取餐時間與最佳步行路線（第一教學大樓 &rarr; 第二教學大樓 &rarr; 綜合大樓 &rarr; 文華食堂）。
   - 點擊右下角 **「開啟 Stitch 圖形化設計原型」** 按鈕，向評審老師展示在 Google Stitch 平台設計的線上原型介面。
